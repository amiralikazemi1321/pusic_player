# Pusic Player 🎵

A simple music player written in Python, built from scratch as a learning project.

## Version

**v0.1**

## Features

* ▶️ Play music files
* 🔎 Search for music in the user's home directory
* 🗑️ Delete MP3 files
* 🚪 Exit the program

## Requirements

* Python 3.10+
* `playsound3`

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/pusic-player.git
cd pusic-player
```

Create a virtual environment:

```bash
python3 -m venv .venv
```

Activate it:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Pusic Player:

```bash
python3 main.py
```
